En la actualidad, el pádel es un deporte en crecimiento, y analizar su juego exige registrar los golpes de cada jugador, una tarea costosa si se hace a mano.
Por ello, el objetivo principal de este trabajo es crear un sistema que los clasifique de forma automática en un partido de pádel.
Sobre este sistema se construye una herramienta que permite a clubes, equipos y profesionales analizar el juego de cada jugador.
Para clasificar cada golpe, es necesario conocer antes cuándo se produce y qué jugador lo da.
Con este fin, el sistema combina el sonido del golpe con el movimiento de los jugadores y de la pelota.

A lo largo de este documento se presenta una herramienta propia de etiquetado, con la que se ha anotado el tipo de cada golpe de los datos de partida, que no lo incluían.
Asimismo, se adaptan al pádel modelos diseñados para otros deportes de raqueta o para otras tareas.
Además, se evalúa cada parte del sistema y el sistema completo en distintos torneos, y cada resultado se acompaña de un intervalo de confianza calculado mediante Monte Carlo.

Por último, se incluye el visor web, la herramienta que muestra las estadísticas de cada jugador y de cada punto a partir de los resultados del sistema.

\vspace{\baselineskip}
\noindent\textbf{Palabras clave:} pádel, visión artificial, aprendizaje profundo, clasificación de golpes, detección por sonido, estimación de la postura, análisis del rendimiento, herramienta de análisis.
