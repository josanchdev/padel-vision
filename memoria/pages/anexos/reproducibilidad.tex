Este anexo explica paso a paso cómo instalar el sistema, comprobar que funciona, obtener los modelos, procesar un punto y verlo en el visor.
Todos los comandos se ejecutan desde la carpeta principal del repositorio \url{https://github.com/josanchdev/padel-vision}.

\section{Instalación}

El sistema está escrito en Python 3.11 y el visor web necesita Node.js, que solo hace falta instalar para usar el visor.
Las dependencias de Python se gestionan con uv, una herramienta que sustituye a pip y al fichero \texttt{requirements.txt}: lee de los ficheros \texttt{pyproject.toml} y \texttt{uv.lock} qué paquetes hacen falta y en qué versión exacta, y crea el entorno por sí misma.
Si no se tiene, uv se instala con pip:
\begin{lstlisting}[style=terminal]
$ pip install uv
\end{lstlisting}

Con uv instalado, el siguiente comando crea el entorno e instala todo lo necesario:
\begin{lstlisting}[style=terminal]
$ uv sync --all-packages
\end{lstlisting}

Para comprobar que la instalación es correcta se ejecutan las pruebas automáticas y la revisión del estilo y de los tipos de datos (\cref{sec:pruebas}):
\begin{lstlisting}[style=terminal]
$ uv run pytest
$ uv run ruff check . && uv run mypy
\end{lstlisting}
Si ninguno de los dos comandos muestra errores, el sistema está listo.
El código usa la tarjeta gráfica cuando hay una disponible y, si no, el procesador.

\section{Datos y modelos}

Ni los vídeos de los conjuntos de datos ni los modelos entrenados se distribuyen con el código.
Los datos se descargan de los sitios que indica el fichero \texttt{data/README.md}, y con ellos se entrenan los modelos del sistema.

El detector de golpes por sonido se entrena con un único comando, que utiliza los 99 puntos de CVSPORTS:
\begin{lstlisting}[style=terminal]
$ uv run python scripts/train_audio_detector.py
\end{lstlisting}

La red de la pelota necesita dos pasos.
Primero se extraen los fotogramas con la pelota anotada de cada final de PadelTracker100, la masculina para entrenar y la femenina para evaluar.
Después se entrena la red con ellos:
\begin{lstlisting}[style=terminal]
$ PT=data/raw/padeltracker100
$ uv run padel-cv extract-ball-frames $PT/2022_BCN_FinalM_1.mp4 \
    --ball $PT/2022_BCN_FinalM_1_ball.json -o data/cache/ball_frames/finalM
$ uv run padel-cv extract-ball-frames $PT/2022_BCN_FinalF_1.mp4 \
    --ball $PT/2022_BCN_FinalF_1_ball.json -o data/cache/ball_frames/finalF
$ uv run padel-ball-train --model tracknetv3 --epochs 40 --augment \
    --train-dir data/cache/ball_frames/finalM \
    --val-dir data/cache/ball_frames/finalF \
    --out runs/ball_full/tracknetv3.pt
\end{lstlisting}

El clasificador del tipo de golpe también se entrena en dos pasos.
El primero calcula la postura y la pelota de los 99 puntos, y el segundo entrena el clasificador con ellas y con el etiquetado propio:
\begin{lstlisting}[style=terminal]
$ uv run python scripts/extract_rally_features.py
$ uv run python scripts/train_shot_classifier.py
\end{lstlisting}

\section{Procesar un punto}

Con los modelos disponibles, un punto se procesa de principio a fin con este comando:
\begin{lstlisting}[style=terminal]
$ uv run python scripts/demo_full_pipeline.py PUNTO.mp4 -o anotado.mp4
\end{lstlisting}
El comando ejecuta el sistema completo y escribe un vídeo con el instante, el jugador y el tipo de cada golpe dibujados encima.
Si el torneo del vídeo aún no tiene la pista marcada, se abre antes una ventana para marcarla con seis clics.
La pista se guarda y se reutiliza en todos los puntos de ese torneo.

\section{Ver los puntos en el visor}

El visor no procesa vídeo, solo muestra puntos ya procesados.
Para prepararlos se usa este comando, que admite uno o varios vídeos:
\begin{lstlisting}[style=terminal]
$ uv run python scripts/export_points.py PUNTO1.mp4 PUNTO2.mp4
\end{lstlisting}
Ejecuta el mismo sistema que el comando anterior sobre cada vídeo y guarda el vídeo procesado y sus datos en \texttt{packages/web/public/points/}, que es la carpeta de la que el visor lee los puntos.

Después se lanza el visor:
\begin{lstlisting}[style=terminal]
$ cd packages/web
$ npm install    # solo la primera vez
$ npm run dev
\end{lstlisting}
Basta con abrir en el navegador la dirección \texttt{http://localhost:5173}.

\section{Herramientas de marcado}

Las dos herramientas de marcado se abren por separado con estos comandos:
\begin{lstlisting}[style=terminal]
$ uv run padel-cv annotate-court PUNTO.mp4
$ uv run padel-cv annotate-types PUNTO.mp4 -o data/labels/shot_types/
\end{lstlisting}
El primero marca la pista de un torneo y el segundo el tipo de cada golpe de un punto.

\section{Reproducir las cifras}

Cada cifra de la memoria sale de un fichero de resultados que escribe un script del repositorio.
La lista de esos ficheros y de los scripts que los generan está en \texttt{docs/metrics/README.md}.
